技术栈：Hexo 8 + 主题 Mustom（fork 进仓库，不是 submodule）+ 自托管的 live2d-widget 看板娘 + 从 WordPress 插件 ShiftNav 移植出来的移动端抽屉菜单。全站资源自托管，不依赖作者 CDN（站点配置里 `CDN_ENABLE: false`）。

## 相对原版改了什么

| 位置 | 改动 |
| --- | --- |
| `themes/mustom/_config.yml` | 菜单只留 首页 / 归档 / 关于；联系方式只留 GitHub；清空作者的网易云歌单 id；改 manifest 名称 |
| `themes/mustom/layout/_partial/frame.ejs` | 在 `</body>` 前注入 ShiftNav 与看板娘的资源引用 |
| `themes/mustom/source/asset/js/main.js` | 删掉主题自带的 `L2Dwidget` 初始化，函数体改成直接回调，避免两套看板娘抢同一个 canvas |
| `themes/mustom/source/asset/js/plugin/` | 删掉不再被引用的 `L2Dwidget.min.js` / `L2Dwidget.0.min.js` |
| `source/live2d/` | live2d-widgets 1.0.1 的 `dist`，模型取自 [HesperusVenus/live2d](https://github.com/HesperusVenus/live2d) 的 umaru（Cubism 2），换装按钮已关掉 |
| `source/shiftnav/` | ShiftNav 1.8.2 的 css/js + dark skin + jQuery 3.7.1 + 一个把主题菜单搬进抽屉的胶水脚本 |

## 看板娘

用的是 <https://github.com/stevenjoezhang/live2d-widget>（npm 包名是复数 `live2d-widgets`）。它自 1.0 起不再需要后端 API，模型清单写在 `source/live2d/waifu-tips.json` 的 `models` 字段里，我指到 `/asset/live2d/umaru/model.json`。渲染核心是仓库自带的 `dist/live2d.min.js`，即 Live2D Cubism 2 Web SDK，所以 umaru 这种 `.moc` 老模型可以直接用。模型本身来自 <https://github.com/HesperusVenus/live2d>，那是个仓库根没有 LICENSE 的个人合集，用的是 pio 那套 `live2d_model.json` 字段（`hit_areas`、`expressions`、`sound`），widget 一样能读。

想换模型：往 `source/asset/live2d/` 放一个新模型目录，再在 `waifu-tips.json` 的 `models` 里加一条，`paths` 指向它的 model json；`loader.js` 的 `tools` 数组控制右下角按钮（`hitokoto` 一言、`photo` 拍照、`info` 介绍、`quit` 关闭）。

## ShiftNav

ShiftNav 是 WordPress 插件，前端本身只是「一份 CSS + 一个 jQuery 插件 + 一段 off-canvas DOM」，所以移植不需要 WordPress：

1. `jquery.min.js` → `shiftnav.min.js`（原样取自插件 SVN trunk）
2. `shiftnav_data` 这个全局对象原本是 WP 用 `wp_localize_script` 注入的，我在胶水脚本里手工补齐了它读取的 16 个键
3. 抽屉 DOM 照 vcb-s 线上渲染结果的结构搭：`.shiftnav[data-shiftnav-id] > .shiftnav-inner > nav.shiftnav-nav > ul.shiftnav-menu`，开关按钮 `#shiftnav-toggle-main.shiftnav-toggle[data-shiftnav-target]`
4. 菜单项从主题渲染好的 `.p-menus .p-menu` 里读；主题是用 JS 异步填充这块 DOM 的，所以胶水脚本每 250ms 轮询一次，拿到内容就停
5. `shift_body` 留空，即不做「推挤主体」的位移，抽屉直接盖在上面——主题的布局有自己的 fixed 头部，推 body 会错位
6. 断点 991px：宽屏隐藏 ShiftNav 开关、用主题自带抽屉；窄屏反过来，并给 `.m-header` 让出左上角的位置
